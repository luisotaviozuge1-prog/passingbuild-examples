# Passing Build examples

Every GitHub Actions example published on [Passing Build](https://passingbuild.com) lives here. All of them are checked by actionlint on every push; the ones that can run on a clean GitHub-hosted runner (no secrets, no third-party services, no files from your own project) also run for real, and the article links to that run. Snippets (partial workflows quoted in an article) are kept as `.snippet.yaml` for reference; they are not linted or run on their own.
